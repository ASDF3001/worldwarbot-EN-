# World War Bot (English Edition)

A strategic territory conquest & diplomacy simulation bot for Discord.

## Features
- **Territory Warfare**: Attack, conquer, and reinforce territories with realistic world maps.
- **Deep Diplomacy**: Sign 24-hour Peace Treaties, declare formal wars, form bilateral alliances, or create multilateral diplomatic Camps.
- **AI Daily Newspaper**: Automatically generates dramatic daily news recaps of world events via Gemini Flash.
- **Resource Management**: Manage Gold, Oil reserves, tech upgrades, and War Bonds.
- **Trophy & Titles System**: Unlock achievements and equip titles.
- **Interactive GUI**: Full Discord UI components (buttons, selects, modals).

## Setup
1. Clone repository:
   ```bash
   git clone https://github.com/ASDF3001/worldwarbot-EN-.git
   cd worldwarbot-EN-
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Create `.env` file:
   ```env
   DISCORD_BOT_TOKEN=your_bot_token_here
   GEMINI_API_KEY=your_gemini_api_key_here
   GEMINI_BASE_URL=https://makigumo.yuto-miya-12.workers.dev/ # optional proxy
   ```
4. Run the bot:
   ```bash
   python main.py
   ```
